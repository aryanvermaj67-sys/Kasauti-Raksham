# Hindi review sheet

For the person who reads Hindi well. Each row is a message the app shows (English on the left, Hindi in the middle). Words in curly braces, like {instrument_name}, are filled in by the app: leave them exactly as they are. Please read the Hindi and write the corrected sentence in the last column if anything sounds wrong, stiff, or could scare or mislead someone. Tick nothing: only write corrections. The app never says "safe", "verified" or "genuine"; check that no Hindi sentence says that either.
